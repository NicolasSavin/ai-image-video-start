## 1. Генерация картинок в браузере (самое простое)

| Сайт | Нужен аккаунт? | Качество | Ссылка |

## 2. Как писать хорошие промпты

### Простая формула:
```
[что хочешь] + [стиль] + [освещение] + [качество]
```

### Примеры:

**Русский:**
- красивая девушка в киберпанк стиле, неоновый свет, высокая детализация
- кот в космосе, стиль студии Ghibli, мягкий свет
- фантастический замок на скале, закат солнца, эпичный стиль

**Английский (часто работает лучше):**
- beautiful girl in cyberpunk style, neon lights, highly detailed, 8k
- cat in space, studio ghibli style, soft lighting
- fantasy castle on a cliff, sunset, epic atmosphere, cinematic
